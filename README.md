# Employee Management

This repository contains the employee management application, built with [Blazor WASM application](https://blazor.syncfusion.com/documentation/getting-started/blazor-webassembly-app) and Entity Framework 7.0 to illustrate performing CRUD operations (Add, Delete, Edit and etc).

## Prerequisites

* Visual Studio 2022 or later
* Visual Studio Code
* SQL Server 2019

## How to run the project

1. Clone or download this repository to a location in your system.
2. Open the solution file using the [Visual Studio](https://visualstudio.microsoft.com/vs/) or [Visual Studio code](https://code.visualstudio.com/).
3. Restore the NuGet packages by rebuilding the solution or run `dotnet restore`.
4. Change the connection string in the appsettings.json file that points to your SQL Server.
5. Build the project to ensure there are no compilation errors.
6. Run the project.

Optional CLI Commands:

```powershell
dotnet restore
dotnet build
```
